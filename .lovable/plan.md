# План за възстановяване на GitHub синхронизацията

## Цел
Да се премахне повтарящата се грешка за липсващ достъп до `miroslav6767/ellaimoti` и проектът отново да се синхронизира.

## Стъпки
1. В **Workspace settings → Git → GitHub** ще се провери коя GitHub връзка използва проектът и дали инсталацията е активна.
2. В GitHub App настройките за същата инсталация ще се потвърди, че `miroslav6767/ellaimoti` е изрично избрано, след което промяната ще се запази.
3. В Lovable ще се използва **Reconnect**, за да се обнови достъпът на съществуващата връзка, вместо да се създава ново хранилище.
4. Ще се повтори синхронизацията от Git секцията на проекта.
5. Ако грешката остане, ще се провери дали хранилището е под различен GitHub акаунт/инсталация или инсталацията е блокирана. При потвърден правилен достъп проблемът ще бъде изпратен до Lovable Support с адреса на проекта, хранилището и точния текст на грешката.

## Важно
Няма да разкачаме проекта или да създаваме ново хранилище, преди да потвърдим инсталацията, защото това може да прекъсне текущата връзка и да доведе до второ repository.
